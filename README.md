# ⚡ بَرق | منصة القراءة والتلوين

تطبيق تعليمي عربي للأطفال يجمع بين **تقييم القراءة** و**التلوين**، يعمل على الجوال واللوحي والحاسوب،
ويمكن تثبيته على الشاشة الرئيسية والعمل **بدون إنترنت**.

إعداد وتصميم: أ. عائشة البروانية

## المزايا

- **تقييم القراءة**: حساب الكلمات تلقائيًا، مؤقّت يمكن إيقافه ومتابعته، عدّاد أخطاء بزر كبير مع تراجع،
  ثم حساب السرعة (كلمة/دقيقة) والدقّة ومنح وسام (ذهبي / فضي / نحاسي) مع عبارة تشجيع.
- **مكتبة الطالب**: سجلّ بكل القراءات مع إحصاءات ورسم بياني لتطوّر السرعة، وإمكانية حذف أي قراءة.
- **التلوين**: ٩ لوحات جاهزة (الشمس، البيت، السمكة، الفراشة، الزهرة، الصاروخ، القطة، المنطاد، وصفحة رسم حر).
  التلوين بلمس أي جزء، أو الرسم الحر بالقلم، مع ممحاة وثلاثة أحجام و١٨ لونًا وزر تراجع.
- **معرض الرسومات**: حفظ اللوحات داخل ملف الطالب، مع تنزيل أي لوحة كصورة.
- **مكافأة بعد القراءة**: زر ينقل الطالب مباشرة من نتيجة القراءة إلى التلوين.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> ملاحظة: العمل بدون إنترنت (Service Worker) وتثبيت التطبيق يحتاجان إلى تشغيل الموقع عبر `http://localhost`
> أو رابط `https`، ولا يعملان عند فتح الملف بنظام `file://`.

## النشر ليعمل من أي جهاز (GitHub Pages)

1. من صفحة المستودع: **Settings → Pages**.
2. في **Source** اختر `Deploy from a branch`، ثم الفرع `main` والمجلد `/ (root)`.
3. احفظ، وانتظر دقيقة، ثم افتح الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.
4. على الجوال: افتح الرابط ثم **إضافة إلى الشاشة الرئيسية** ليعمل كتطبيق مستقل وبدون إنترنت.

## الملفات

| الملف | الوصف |
| --- | --- |
| `index.html` | التطبيق كاملًا (واجهة + أنماط + برمجة) بدون أي مكتبات خارجية |
| `manifest.webmanifest` | بيانات تثبيت التطبيق على الأجهزة |
| `sw.js` | التخزين المؤقّت للعمل بدون إنترنت |
| `assets/` | أيقونات التطبيق |

## الخصوصية

كل البيانات (الطلاب، القراءات، الرسومات) تُحفظ في `localStorage` داخل جهاز المستخدم فقط،
ولا تُرسل إلى أي خادم. مسح بيانات المتصفح يمسحها.
