# 🌸 ريشة القارئ | القراءة التوجيهية

تطبيق عربي للأطفال: تظهر اللوحة، وأسفلها **أمر واحد** يقرأه الطفل ثم ينفّذه **بالتلوين** على اللوحة نفسها.
لا ينتقل إلى الأمر التالي إلا بعد أن يستخدم اللون المطلوب فعلًا.

بلا تسجيل دخول وبلا حفظ بيانات: يفتح الطفل الموقع ويلعب مباشرة.

إعداد وتصميم: أ. عائشة البروانية

## التجربة

1. **شاشة ترحيب** تشرح الفكرة في ثلاث خطوات: اقرأ الأمر، لوّن المطلوب، تحقّق وانتقل.
2. **اختيار لوحة** من عشرين لوحة عُمانية (وادٍ، صحراء، ساحل، سوق، قلعة، أفلاج، خريف ظفار، مسجد…).
3. **التلوين**: لمسة واحدة داخل أي شكل تملؤه باللون كاملًا، ويتوقف اللون عند خطوط الرسم.
4. **التحقّق**: إن كان اللون صحيحًا تظهر «أحسنت» وينتقل تلقائيًا، وإلا ظهرت رسالة إرشادية.
5. **النهاية**: عدد الأوامر المنفَّذة من المحاولة الأولى، مع إمكانية تنزيل اللوحة الملوّنة.

## الأوامر

لكل لوحة **ثمانية أوامر**: سبعة أوامر تلوين تتدرّج في الصعوبة (حجم، مكان، عدد)،
ثم **سؤال فهم** ختامي يُجاب عنه بالتلوين، مثل:

> لَوِّنْ بِالْأَزْرَقِ الشَّيْءَ الَّذِي يَجْرِي فَيَسْقِي الْمَزَارِعَ.

كل الأوامر مشكَّلة بالكامل لتناسب القراءة الجهرية، ومكتوبة بخط نسخي واضح.

## الهوية

طابع «حديقة باستيل»: خلفية كريمية، وألوان وردية وزرقاء وخضراء هادئة، وزهور مرسومة داخل التطبيق نفسه
(لا أيقونات جاهزة)، وخطّان فقط: خط عريض لطيف للعناوين وخط نسخي للنصوص المشكَّلة.

## التشغيل

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> التلوين يحتاج إلى تشغيل الموقع عبر رابط (`http://localhost` أو `https`)، ولا يعمل بفتح الملف مباشرة
> بنظام `file://` لأن المتصفح يمنع قراءة بيانات الصورة حينها.

## النشر (GitHub Pages)

من صفحة المستودع: **Settings → Pages**، ثم اختر الفرع والمجلد `/ (root)`.
بعدها يصبح الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`، ويمكن إضافته إلى شاشة الجوال ليعمل بدون إنترنت.

## الملفات

| الملف | الوصف |

| `index.html` | التطبيق كاملًا بلا أي مكتبات خارجية |
