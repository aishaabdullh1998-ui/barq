# 🪶 ريشة القارئ | القراءة التوجيهية

تطبيق عربي للأطفال مخصّص لـ **القراءة التوجيهية**: تظهر اللوحة، وأسفلها **أمر واحد فقط**،
ينفّذه الطالب على اللوحة نفسها، ثم يتحقّق التطبيق من تنفيذه قبل الانتقال إلى الأمر التالي.

يعمل على الجوال واللوحي والحاسوب، ويمكن تثبيته على الشاشة الرئيسية والعمل **بدون إنترنت**.

إعداد وتصميم: أ. عائشة البروانية

## طريقة العمل

1. سجّل بيانات المعلّم والصف، ثم أضف الطلاب.
2. اختر لوحة من **٢٠ لوحة** عُمانية، لكل واحدة **١٠ أوامر** مشكَّلة.
3. يقرأ الطالب الأمر المعروض أسفل اللوحة وينفّذه عليها.
4. عند الضغط على **تحقّق**:
   - إن كان التنفيذ صحيحًا: تظهر «أحسنت ✅» وينتقل التطبيق تلقائيًا إلى الأمر التالي.
   - وإلا: تظهر رسالة إرشادية تحدّد المطلوب، ولا ينتقل.
5. في النهاية تظهر النتيجة (عدد الأوامر المنفَّذة من المحاولة الأولى) مع وسام،
   وإمكانية حفظ اللوحة في معرض الطالب أو تنزيلها.

## التحقّق من التنفيذ

يُحلَّل كل أمر آليًا لتحديد الأداة المطلوبة واللون المطلوب، وتُختار الأداة تلقائيًا عند عرض الأمر:

| صيغة الأمر | الأداة | مثال |
| --- | --- | --- |
| لَوِّنْ… | تلوين 🖌️ | لَوِّنِ النَّخْلَةَ بِاللَّوْنِ الْأَخْضَرِ |
| ارْسُمْ… | رسم ✏️ | ارْسُمْ سَمَكَتَيْنِ فِي الْمَاءِ |
| اكْتُبْ… | كتابة 🔤 | اكْتُبِ اسْمَكَ فَوْقَ الصَّخْرَةِ |
| ضَعْ دَائِرَةً حَوْلَ… | دائرة ⭕ | ضَعْ دَائِرَةً حَوْلَ الطِّفْلِ |
| ضَعْ خَطًّا تَحْتَ… | خط ➖ | ضَعْ خَطًّا تَحْتَ الْجَبَلِ |
| ضَعْ مُثَلَّثًا حَوْلَ… | مثلث 🔺 | ضَعْ مُثَلَّثًا حَوْلَ الْبُرْجِ |
| اشْطُبْ… | شطب ✖️ | اشْطُبْ ٣ نَخَلَاتٍ |

يتأكّد التطبيق من أمرين: أن الطالب أضاف العمل المطلوب في هذه الخطوة، وأنه استخدم اللون المطلوب
عند وجوده. أمّا الأوامر المفتوحة (مثل: اكتب كلمة لها علاقة بالبحر) فيتحقّق من التنفيذ فقط،
ويبقى الحكم النهائي للمعلّم عبر زر **تجاوز**.

## التشغيل

افتح `index.html` في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

> العمل بدون إنترنت وتثبيت التطبيق يحتاجان إلى `http://localhost` أو رابط `https`،
> ولا يعملان عند فتح الملف بنظام `file://`.

## النشر ليعمل من أي جهاز (GitHub Pages)

1. من صفحة المستودع: **Settings → Pages**.
2. في **Source** اختر `Deploy from a branch`، ثم الفرع والمجلد `/ (root)`.
3. افتح الرابط: `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`.
4. على الجوال: **إضافة إلى الشاشة الرئيسية** ليعمل كتطبيق مستقل وبدون إنترنت.

## الملفات

| الملف | الوصف |
| --- | --- |
| `index.html` | التطبيق كاملًا (واجهة + أنماط + برمجة) بدون أي مكتبات خارجية |
| `sheets.js` | نصوص الأوامر ولوحاتها، مولّدة من ملف «اتَّبِعِ التَّعْلِيمَاتِ» |
| `assets/sheets/` | صور اللوحات العشرين |
| `manifest.webmanifest` | بيانات تثبيت التطبيق على الأجهزة |
| `sw.js` | التخزين المؤقّت للعمل بدون إنترنت |

## الخصوصية

كل البيانات (الطلاب، اللوحات المكتملة، الصور المحفوظة) تُحفظ في `localStorage` داخل جهاز المستخدم
فقط، ولا تُرسل إلى أي خادم.
